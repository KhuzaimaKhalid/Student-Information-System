# Student Information System 

This is a simple Java console application that simulates a student information system using object-oriented programming (OOP) principles such as inheritance and encapsulation.

## 📌 Features

- Collects and displays student personal information
- Calculates exam percentage and CGPA
- Calculates total course fee based on number of courses

## 🧠 OOP Concepts Used

- **Inheritance**: `Exam` and `Finance` classes inherit from the `Student` base class
- **Encapsulation**: Data members are accessed and modified through constructors and methods
- **Method Overriding**: Custom display and calculation methods
